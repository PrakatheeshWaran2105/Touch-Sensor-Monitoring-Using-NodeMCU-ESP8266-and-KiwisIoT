# Touch-Sensor-Monitoring-Using-NodeMCU-ESP8266-and-KiwisIoT
Touch Sensor Monitoring using NodeMCU ESP8266 and TTP223 touch sensor with real-time touch detection and status monitoring through the KiwisIoT platform.
Touch Sensor Monitoring Using NodeMCU ESP8266 and KiwisIoT
About the Project
The Touch Sensor Monitoring is an IoT-based project designed to detect touch interactions and monitor sensor status in real time.

Using a NodeMCU ESP8266 microcontroller and a touch sensor module (TTP223), the system detects when a user touches the sensor and sends the touch status to the KiwisIoT platform through Wi-Fi. Users can remotely monitor touch detection events and sensor status through the KiwisIoT dashboard.

By integrating KiwisIoT, this project demonstrates a simple and effective approach to touch detection, real-time status monitoring, and IoT-based device connectivity.
